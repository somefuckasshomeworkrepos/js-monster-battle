# Битва з монстром

Консольна гра на JavaScript для Node.js. Гравець і монстр по черзі атакують один одного, доки здоров'я когось із них не стане нульовим.

## Запуск

У терміналі VS Code перейдіть до папки проєкту та запустіть:

```bash
node index.js
```

Гра використовує об'єкти `player` і `monster`, масив `inventory`, а також функції `attack()`, `monsterAttack()` і `showStatus()`. Щоб підготувати скриншот для здачі, запустіть гру в терміналі VS Code і зробіть знімок екрана так, щоб було видно команду та повідомлення про результат.
