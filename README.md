# Гра «Битва з монстром»

Консольна гра на JavaScript для Node.js. Вводьте команду `attack`, щоб атакувати монстра.

## Запуск

У терміналі з цієї теки виконайте:

```bash
node index.js
```
Команди в грі:

- `attack` — атакувати монстра.
- `status` — показати здоров'я гравця та монстра.
- `quit` — завершити гру.
