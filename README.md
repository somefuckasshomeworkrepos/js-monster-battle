# Гра «Битва з монстром»

Консольна гра на JavaScript для Node.js. Вводьте команду `attack`, щоб атакувати монстра; він відповість, якщо залишиться живим. Бій триває, доки здоров'я когось із учасників не стане рівним нулю.

## Запуск

У терміналі з цієї теки виконайте:

```bash
node main.js
```

Гра не потребує встановлення сторонніх пакетів.

Команди в грі:

- `attack` — атакувати монстра.
- `status` — показати здоров'я гравця та монстра.
- `quit` — завершити гру.

## Публікація на GitHub

Створіть порожній репозиторій на GitHub, а тоді виконайте команди в цій теці, підставивши адресу свого репозиторію:

```bash
git init
git add main.js README.md
git commit -m "Додати гру Битва з монстром"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГІН/ВАШ_РЕПОЗИТОРІЙ.git
git push -u origin main
```

Після цього посилання на репозиторій матиме вигляд `https://github.com/ВАШ_ЛОГІН/ВАШ_РЕПОЗИТОРІЙ`.

## Скріншот для здачі

Запустіть `node main.js` у терміналі VS Code і зробіть знімок екрана так, щоб було видно команду запуску, перебіг битви та повідомлення про перемогу або поразку. У Linux можна використати `PrtSc` або `Shift+PrtSc`.
